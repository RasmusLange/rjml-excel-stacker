Sheet stacker

Load a workbook, choose which sheets and which columns to keep, and get one stacked sheet back. Columns are matched by header text, so sheets can have their columns in different orders. Headers can sit anywhere in the sheet and can span several rows.

5. Duplicates

The first occurrence is kept, in sheet order. Source sheet and Source row are never compared, so duplicates across sheets are caught. In column mode, rows with an empty value in that column are always kept.
